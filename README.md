# lipalink-system

LipaLink : gestion des dettes et créances, avec sauvegarde et synchronisation en ligne.

| Dossier             | Contenu                                                                 |
| ------------------- | ----------------------------------------------------------------------- |
| `lipa-link-mobile/` | Application mobile Flutter (SQLite local, sauvegarde en ligne)          |
| `lipa-link-admin/`  | Serveur Node.js + SQLite et dashboard React d'administration            |

Administration en ligne : https://lipalink.liviatech.store

Voir [lipa-link-admin/README.md](lipa-link-admin/README.md) pour lancer et déployer le serveur.
